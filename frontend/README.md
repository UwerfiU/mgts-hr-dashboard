# Дашборд стажировок МГТС

Локальный HR-прототип на React, TypeScript, Vite и Recharts. Для запуска нужен Node.js 22.18 или новее.

```bash
cd frontend
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. По умолчанию открывается вариант **Б** с синтетическими данными. Переключатель **А / Б** запоминает оформление в браузере и сохраняет фильтры при переключении.

## Демонстрация

1. На «Обзоре» посмотрите охват и динамику за апрель–сентябрь. Сузьте период до апреля и переключите **А / Б**. Затем нажмите «Сбросить».
2. В июле средняя парная разница для «Самостоятельности» составляет −0,2 балла по пяти парам. Раскройте «Карточки стажёров» и откройте «Стажёр 01», чтобы посмотреть оценки по циклам и разрешённые отзывы.
3. На странице «Обратная связь» выберите роль «Наставники» и категорию «Нагрузка». Справа виден статус AI-анализа.
4. Нажмите «Демо» в шапке и выберите сценарий «Пропуск цикла и ноль». У стажёров в мае есть точка с оценкой 0, а в июле у обоих рядов разрыв. «Таблица значений» под графиком показывает число ответов рядом с каждой оценкой.
5. В том же списке доступны неизвестный план, несопоставимые шкалы, отсутствие пар, пустой срез, ошибка с повтором запроса, недоступная детализация и устаревшая синхронизация. Прямую ссылку на закрытую карточку можно проверить по пути `/interns/intern-01?demo=restricted`.

## Подключение Backend

Экранные компоненты используют `DataClient`. Типы и обе реализации находятся в `src/data/`. Смена режима выполняется при запуске. Чтобы Vite направлял запросы к локальному Backend, укажите его адрес. В примере Backend слушает порт 8000.

```bash
VITE_DATA_MODE=http API_PROXY_TARGET=http://127.0.0.1:8000 npm run dev
```

В HTTP-режиме клиент запрашивает `GET /api/v1/meta`, `GET /api/v1/metrics` и `GET /api/v1/feedback`. По умолчанию используется тот же origin. При отдельном origin с настроенным CORS можно передать его в `VITE_API_BASE_URL`. Статическая сборка использует адрес API, заданный при сборке, а сервер хостинга должен направлять переходы на `/interns/…` и `/feedback` в `index.html`.

`src/data/types.ts` описывает контракт, который сейчас ожидают экраны. Показатели и доступы поступают через клиент данных. HTTP-режим проверен с тестовым сервером по этому контракту. В текущей реализации Backend справочники `/meta` и список текстов `/feedback` имеют другую структуру. Для подключения команды должны согласовать формат или добавить адаптер в клиент. Сценарии демо доступны только в режиме моков. Ошибки HTTP отображаются в интерфейсе.

```bash
npm test
npm run build
```
