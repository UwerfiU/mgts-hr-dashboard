# Дашборд стажировок МГТС

Локальный HR-прототип на React, TypeScript, Vite и Recharts. Для запуска нужен Node.js 22.18 или новее.

```bash
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. Используется единое оформление **Б** с синтетическими данными. В шапке остаётся статичная пометка «Демо», без меню сценариев.

Вариант Б использует [Liquid Glass](https://github.com/Glass-HQ/liquid-glass) версии 0.0.2: скругления 32 px, преломляющую окантовку и блик, который следует за курсором. Материал Clear с преломлением 60 px рисуется на собственной непрозрачной подложке, а центральная поверхность под данными остаётся плотной и светлой. Текст и SVG графиков находятся поверх материала и не искажаются. Библиотека загружается отдельным модулем. Без WebGPU, при ошибке материала или включённом системном контрастном режиме сохраняются читаемые карточки. При уменьшении движения блик неподвижен. Полная проверка нативного Safari ещё не проводилась.

В каталоге восемь демопоказателей. К самостоятельности, пониманию задач и нагрузке добавлены качество работы, командное взаимодействие, инициативность, освоение навыков и мотивация. Названия и шкалы находятся в слое данных. Это синтетические примеры для проверки интерфейса, а не согласованный состав будущих Google Forms. В графике отдельно показаны средние оценки последнего выбранного цикла; при пропуске отображается «Нет оценки».

В обзоре одновременно показаны **пять виджетов**. Если выбрать из списка показатель, которого ещё нет в сетке, он заменяет пятый виджет. Нажатие на название или стрелку переносит к подробной динамике, распределению и диаграмме парных различий. Все графики используют общий срез по циклам и участникам. Ошибка одного запроса не скрывает остальные доступные показатели; расчёты остаются в клиенте моков или Backend.

## Демонстрация

1. На «Обзоре» посмотрите охват и динамику за апрель–сентябрь. Сузьте период до апреля. Затем нажмите «Сбросить».
   Переключите показатель на «Мотивация»: виден спад к июлю и частичное восстановление. Сравните с «Освоением навыков», где в демоданных оценки растут.
2. В июле средняя парная разница для «Самостоятельности» составляет −0,2 балла по пяти парам. Раскройте «Карточки стажёров» и откройте «Стажёр 01», чтобы посмотреть оценки по циклам и разрешённые отзывы.
3. На странице «Обратная связь» выберите роль «Наставники» и категорию «Нагрузка». Справа виден статус AI-анализа.
4. Для проверки сценария «Пропуск цикла и ноль» откройте `/?demo=gap`. У стажёров в мае есть точка с оценкой 0, а в июле у обоих рядов разрыв. «Таблица значений» под графиком показывает число ответов рядом с каждой оценкой.
5. Остальные тестовые сценарии доступны через параметр `?demo=<id>`; идентификаторы перечислены в `src/data/fixtures.ts` (`demoScenarios`). Прямую ссылку на закрытую карточку можно проверить по пути `/interns/intern-01?demo=restricted`.

## Подключение Backend

Экранные компоненты используют `DataClient`. Типы и обе реализации находятся в `src/data/`. Смена режима выполняется при запуске. Чтобы Vite направлял запросы к локальному Backend, укажите его адрес. В примере Backend слушает порт 8000.

```bash
VITE_DATA_MODE=http API_PROXY_TARGET=http://127.0.0.1:8000 npm run dev
```

В HTTP-режиме клиент запрашивает `GET /api/v1/meta`, `GET /api/v1/metrics` и `GET /api/v1/feedback`. По умолчанию используется тот же origin. При отдельном origin с настроенным CORS можно передать его в `VITE_API_BASE_URL`. Статическая сборка использует адрес API, заданный при сборке, а сервер хостинга должен направлять переходы на `/interns/…` и `/feedback` в `index.html`.

`src/data/types.ts` фиксирует форму ответов для прототипа в тех местах, где FRONTEND.md описывает поля без примера JSON. Среди уточнений есть `coverage.*.percent` для рассчитанного сервером процента и отдельные статусы `empty` и `unavailable`. Если процент отсутствует, интерфейс показывает число ответов. Сценарии демо доступны только в режиме моков. Ошибки HTTP отображаются в интерфейсе.

```bash
npm test
npm run build
```
