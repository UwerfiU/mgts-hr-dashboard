# WP7: Настройка фактических источников (B7) — этап 2

**Зависимости:** материалы и пояснения организаторов (два реальных Excel, доступ к формам с реальными вопросами).
До их получения задание не запускается; на текущих синтетических данных — только демонстрация интерфейса.

## Цель
Сопоставить фактические поля Excel и форм с внутренним каталогом, подтвердить циклы, сравнимость вопросов и правила связывания ответов.

## Файлы в зоне работы
- `backend/config/catalog.yaml` — реальные вопросы/шкалы (замена предположительных)
- `backend/config/sources_excel.yaml`, `sources_forms.yaml` — реальные маппинги
- `backend/app/normalization/` — точечные правки, если фактические форматы потребуют новых типов правил

## Что сделать
1. Сопоставить поля: каждый столбец Excel и ID вопроса формы → внутренний ключ; зафиксировать шкалы (могут отличаться от 1–5).
2. Подтвердить циклы: как в каждом источнике определяется цикл 1–6 (столбец, период, явное поле).
3. Правила связывания «о ком»: по какому ключу ответ наставника привязывается к стажёру; **что делать с записями без надёжной связи**
   (учитываются только агрегированно — зафиксировать в `permissions.yaml`).
4. Пересечение истории и новых ответов: какие записи из Excel и форм являются одними и теми же (по подтверждённому ключу) —
   склеивать только по подтверждённому ключу; до этого источники разделяются (например, по согласованным циклам).
5. Контрольная сверка: несколько строк из каждого Excel вручную сверить с записями в БД после импорта.

## Критерий готовности (BACKEND.md B7)
- Контрольные строки из обоих Excel сверены с БД.
- Известно, какие записи можно объединять, а какие учитываются только агрегированно.

## Отчёт по завершении
Короткий документ (в `tasks/` или в README): карта соответствий «поле источника → внутренний ключ», принятые правила связывания,
список необратимых решений (что склеивается/не склеивается).
