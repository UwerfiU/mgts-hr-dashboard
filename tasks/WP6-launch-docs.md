# WP6: Локальный запуск и расширение аналитики (B6)

**Зависимости:** WP3–5. **Финальный штрих этапа 1.**

## Цель
Проект, который другой участник команды поднимает по инструкции: заполненная синтетическая БД, работа без внешних ключей и интернета, режим подключения форм.

## Файлы в зоне работы
- `README.md` (корень) — полный quickstart
- `backend/app/scripts/seed_demo.py` (новый) — генерация синтетической БД
- `backend/.env.example`, `backend/config/*` — финальная проверка примеров
- `backend/tests/test_seed.py`

## Что сделать
1. **Seed синтетики** (`python -m app.scripts.seed_demo [--reset]`): 5 стажёров × 5 наставников, циклы 1–6, обе анкеты,
   осмысленный «сюжет» для демо (один стабильно слабый показатель, пара с расхождением оценок, негативные комментарии к этапу 2) —
   идеи генератора есть в git-истории (`app/scripts/load_datasets.py`, ветка `--example`). Запись — через нормализацию WP2 (не в обход).
2. **Запуск без интернета**: режим `demo` работает на сохранённой БД; poller форм не стартует, ошибки внешних сервисов не мешают.
3. **README**: структура проекта, quickstart (venv → install → seed → uvicorn → `/docs`), описание режимов (`demo`/`real`),
   как подключить реальные формы (ссылка на чеклист WP4), где лежат конфиги и что в них настраивается.
4. **Гигиена**: в репозитории нет ключей и реальных данных (проход по `.gitignore`, `.env.example` только с плейсхолдерами);
   исходники и настройки примера доступны команде.
5. Расчёты уже выделены в `app/analytics/` (WP5) — проверить, что API не содержит расчётной логики (только вызовы модуля).

## Критерий готовности (BACKEND.md B6)
- Другой участник запускает проект по инструкции.
- Исходники и настройки примера доступны команде; ключи и реальные данные отсутствуют в репозитории.

## Тесты
`seed_demo --reset` → ожидаемые счётчики записей; повторный seed без `--reset` → без дублей; после seed все три маршрута `/api/v1` отвечают 200 на общем наборе.
